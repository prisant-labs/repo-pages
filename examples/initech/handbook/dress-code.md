# Dress code

Business casual, Monday to Thursday.

## Hawaiian Shirt Friday

Friday is Hawaiian Shirt Day. Participation is voluntary in the sense that it is noticed.

| Counts | Does not count |
|---|---|
| Floral print, short sleeves | A floral tie |
| Parrots | A single parrot pin |
| Pineapples | A lei worn over a dress shirt |
| Sunset scenes | Your regular shirt "but in spirit" |

## Accessories

Suspenders are permitted. Management wears them as an example, not as a requirement.

## Flair

Flair is a Chotchkie's thing. It is not part of the Initech dress code. See [Chotchkie's flair policy](../neighbors/chotchkies/flair-policy.md) if you are confused about which job you have.
