# New TPS cover sheets

**From:** Bill Lumbergh, Division Vice President
**To:** All software staff
**Re:** Cover sheets

Hi everyone. Quick note.

Starting today we are putting the **new** cover sheet on all TPS reports before they go out. The old cover sheet is retired. I know some of you have a stack of the old ones in your drawer. That is fine. Please recycle them.

## What changed

| | Old cover sheet | New cover sheet |
|---|---|---|
| Logo | Old logo | New logo |
| Manager initials | One box | Eight boxes |
| Project code | Optional | Required |
| Color | White | Also white |

## Why

Consistency. When a report reaches the client, the first thing they see is the cover sheet. It should be the right one.

## Reminders

If a report goes out without the new cover sheet, I will send a copy of this memo. Possibly more than one copy.

Thanks a bunch.

Bill
