# Software team

We maintain banking software for Initech's clients and keep the office computers running.

## People

See [team.yaml](team.yaml).

## What we own

| Area | Notes |
|---|---|
| Client banking systems | Including the [Y2K remediation](../../projects/y2k-remediation/README.md) |
| Office computers | Ask before installing anything |
| The printer | Reluctantly. See the [incident report](printer-incident-report.md) |

## Asking for help

1. Check [on-call.md](on-call.md) for who is on call.
2. Write down the exact error. "It is broken" is not an error.
3. If the error is about the printer, check [printer-error-codes.json](printer-error-codes.json) first.
