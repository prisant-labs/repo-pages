# Printer incident report

**Device:** fourth-floor laser printer. **Reporter:** Michael Bolton. **State:** resolved, permanently.

## Symptoms

- Jams on every third page.
- Shows `PC LOAD LETTER`. Nobody knows what this means. See [printer-error-codes.json](printer-error-codes.json).
- Reports "paper jam" when there is no paper in it.

## Attempts to fix

| Attempt | Who | Result |
|---|---|---|
| Turned it off and on | Michael | Worked for one page |
| Replaced the toner | Samir | Jammed |
| Read the manual | Peter | The manual also said PC LOAD LETTER |
| Called the vendor | Nina | On hold |

## Resolution

The printer was taken to a field outside town by three members of the software team. It is no longer in service. Facilities has ordered a replacement.

## Lessons

- Error messages should say what to do.
- So should this report. Print to the third floor.
