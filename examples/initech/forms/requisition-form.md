# Notes: requisition form

These notes pair with [requisition-form.html](requisition-form.html).

## Rules the form applies

| Rule | Outcome |
|---|---|
| No cover sheet ticked | Returned |
| Red stapler | Always pending, forwarded to Bill |
| Over the item limit | Denied |
| Everything else | Approved for Tuesday |

Limits come from the [office supplies policy](../handbook/policies/office-supplies.md).

## Why the red stapler is pending forever

Facilities does not stock red staplers. Every request for one so far has come from the same person. See [the requisitions](../data/stapler-requisitions.csv).
