# Tools

| File | What it does |
|---|---|
| [tps_report.py](tps_report.py) | Turns a test run summary into a filled TPS cover sheet |
| [cover_sheet.js](cover_sheet.js) | Renders a cover sheet in the browser |
| [cover-sheet.css](cover-sheet.css) | Print styles for the cover sheet |
| [Makefile](Makefile) | `make tps` runs the filler on the latest test run |
